# Original 3D character assets — import contract

The engine can now load six original Godot-imported GLB character models from this directory. **No GLB files are shipped yet.** The current runtime renders procedural chess-piece placeholders until an original model is committed.

| Chess class | Asset file | Facing |
|---|---|---|
| Pawn | pawn.glb | local -Z |
| Rook | rook.glb | local -Z |
| Knight | knight.glb | local -Z |
| Bishop | bishop.glb | local -Z |
| Queen | queen.glb | local -Z |
| King | king.glb | local -Z |

## Technical requirements
- Original, licensed-to-distribute meshes and PBR materials, with textures embedded in GLB or correctly packaged with the Godot project.
- One chess tile = 1 x 1 world units. Root origin at feet (Y=0), approximate visual height 1.2–1.6 units. Keep silhouettes legible in portrait 720x1280.
- Optional AnimationPlayer in imported scene, clips named exactly `move` and `attack`. The game falls back to procedural pivot motion when clips are absent.
- Visuals should be on the imported root; battle health bars and equipped overlays remain generated by the game.
- Include source authoring files, license/attribution, triangle and material budgets, and mobile-device benchmark results with every final asset pack.
- Do not copy third-party game models or claim commercial-ready art based on generated primitives.

## Integration
The runtime uses `CHARACTER_SCENE_PATHS` and `_load_authored_character` in `scripts/battlefield_3d.gd`. Imported scenes must remain loadable through Godot's `ResourceLoader`. Run the Godot smoke tests and Android export after adding each asset. Verify animations and draw calls on physical devices.
